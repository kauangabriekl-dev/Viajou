# VIAJOU

Rede social de viagens: "Experiências reais de quem já esteve lá." Next.js 16 + banco H2 local (modo PostgreSQL), em português do Brasil.

## Skills do projeto (`.claude/skills/`)

Leia a skill correspondente antes de mexer na área:

| Skill                   | Quando                                              |
| ----------------------- | --------------------------------------------------- |
| `frontend-standards`    | Páginas, componentes, formulários, APIs do Next 16  |
| `backend-standards`     | Server actions, consultas, Zod, uploads             |
| `database-standards`    | Migrations, RLS, triggers, seed                     |
| `ui-design-system`      | Qualquer mudança visual, estados, acessibilidade    |
| `testing-standards`     | Testes e definição de pronto                        |
| `security-standards`    | Auth, permissões, segredos, uploads, dados pessoais |
| `seo-standards`         | Páginas públicas, URLs, metadata                    |
| `travel-platform-rules` | Regras de negócio e de produto                      |

## Comandos

`npm run dev` · `npm run lint` · `npm run typecheck` · `npm test` · `npm run test:db` · `npm run build`

Nada está pronto sem lint, typecheck, testes e build passando, e sem o fluxo afetado exercitado de verdade.
